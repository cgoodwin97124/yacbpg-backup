How to Use

  1. Pick your page size — open 📄 File and choose how many panels you want (1, 4, 6, 12, or 24). Each menu section's panels start collapsed — click a panel's header (e.g. "Page Setup") to expand its options.
  2. Work across pages — open 📄 File → Page Setup → Page: to add, name, switch, and delete pages. Each page has its own number of panels, its own seed, and its own panels; the app-wide settings (image size, art style, NSFW flag) are shared. Generating and both view modes always act on the current page, and images are remembered per page in memory until you reload.
  3. Set the art style — open 🎨 Edit for art style & palette presets, hand-edit the global positive/negative keywords, or view and copy the full list in the Keyword List. To control how literally the AI follows your words, use the Prompt Obedience slider in 📄 File → Page Setup (1–30; 7 is the balanced default). Low values are loose and free, high values are very faithful but with diminishing returns — past ~15 colors oversaturate and halo / text artifacts appear.
  4. Fill in each panel — for every panel, choose up to 3 characters, a location, and an optional action like "kicking the door down". The modifier boxes let you tweak a character's look or mood per panel. Use the Images selector in each panel's header to render 1–4 images from the same prompt (variations of the same scene), 📄 File → Images per Panel sets the default that new and blank panels start at — it is saved with the project, so it is still set the next time you open the app — and its Apply to all button sets every panel at once. A panel renders as long as it has any content — a character, location, or action. Completely empty panels (no prompt beyond the presets) are skipped automatically. The character dropdowns list your saved library characters first, with the "No Character Selected" option at the bottom.
  5. Title and reorder your panels — each panel's title bar has a title box (right of "Panel N", display-only — it isn't added to the prompt). The ⇅ Move chip opens a 1-to-N picker: choose a position to move that panel there, shifting the panels in between (e.g. moving panel 5 to position 2 makes it Panel 2, and the old 2–4 each move up one). Everything about a panel — title, characters, modifiers, location, action, panel seed, image count, and prompt override — moves with it, and the arrangement survives reloads and is included in your settings backup/import.
  6. Use saved descriptions — add reusable character or location descriptions in 📚 Library. They save automatically in your browser and appear in every panel's dropdown. A panel uses a saved character only when you explicitly select it in a character slot; it never draws one in automatically. The ⛶ Full Screen button opens the Library in a full-screen overlay — the same live list, so your edits save as you type — which is a lot easier to work with on a phone; leave it with ← Back to page or Esc. The ⬆ Import… button there pulls saved characters/locations (and actions, if the file has them) out of a project file — a .json backup or a .zip — so you can reuse them in another project; you pick which items to bring in and can edit them first. The 📊 Analysis button opens a matrix of your library items against the current page's panels — a ✅ marks each item a panel uses, and you can edit that panel's per-item description right in the grid (or ＋ Add an unused item to a panel).
  7. Keep a character consistent — use the small ⇤ button on a character slot to copy that character + modifier from the panel directly before it (the Location and Panel Action Prompt rows have the same ⇤ copy buttons). Panel 1 has no previous panel, so its buttons are disabled. Already-set items are overwritten by the copy.
  8. Generate — hit ⚡ Generate All in the menu bar — it sits beside File / Edit / Library / Help and stays visible at the top of the menu (and, if you turn on the matching option in Preferences, it also stays visible in the top header bar while the menu is hidden). Each panel takes a few seconds (multiply by the number of images set for that panel). Or render just one panel: press Enter in its Panel Action Prompt or its header Seed box (use Shift+Enter to add a new line in the action box), or click its 🔄 Generate button. Each image also has its own 🔄 Generate chip above it to regenerate just that image. Each image has its own ✕ Clear this image chip (images only). When a panel has more than one image, a 🗑 Clear Images chip appears that removes all of that panel's images at once while keeping its characters, location, and action. The panel's 🗑 Clear chip removes everything — all images and its characters, locations, and descriptions (this also stops an in-progress generation for that panel). To keep a particular image safe from being overwritten, click its 🔓 Protect chip beneath it — Generate (that image's own chip, the panel's, or ⚡ Generate All) never touches a protected image; a panel Generate simply keeps the protected images and regenerates the rest. Click 🔒 Protected again to unprotect. To reuse a panel's setup, click ⧉ Duplicate — it inserts a full copy (title, characters, modifiers, location, action, panel seed, image count, prompt, protect) right after the original, with no images, and widens the page to show it (up to the 24-panel maximum). When a page already has all 24 panels, Duplicate reflows instead of refusing: your page's last panel is pushed to the top of the next page — creating a new page if there isn't one, and cascading on through any further full pages — and the copy takes that last slot, right after the panel you duplicated. You're asked to confirm first, and told how many panels will move. ＋ Add Panel does the same thing when the page is full, adding the empty panel right after the one you clicked.
  9. Work with your images — each image has ↗ Open (shows it full-size in a new tab) and ⬇ Save (downloads it to your device) chips in the row beneath it; both need an image first. Nothing overlays the images. The button row at the bottom of each panel adds ↗ Open All (opens every image in that panel in new tabs) and ⬇ Save All (.zip) (downloads all of that panel's images packed into a single .zip); these activate once the panel has at least one image. Choose the image size in 📄 File: from 512×512 up to 1920×1080 (16:9) or 1080×1920 (9:16), or a custom size up to 1920×1080. Larger sizes are upscaled from the 768px base generation, so they're a bit softer but still crisp for print/web use. To preview any image at a larger size, hover your pointer over it (computer) or press and hold it (mobile). The preview appears after the delay set in 📄 File → Image Preview Delay (0 shows it instantly), and can be turned off entirely with the Enable image preview checkbox there. Each image also has a 🔓 Protect chip (locks it against regeneration), a ⭐ Cover chip (makes it the panel's representative — it moves to the first slot and gets a ⭐ badge), and an ✕ Clear this image chip (removes just that image). A ⧉ chip copies that image onto other images: it opens a small picker where you tick any of the other images in its own panel — there's a select all shortcut — and/or 1–4 images of another panel on the same page, then press ⧉ Copy image. The image you clicked stays where it is, anything already in a chosen slot is replaced, and a 🔒 protected image is never overwritten (it's skipped and the status line says so). Every copy lands unprotected, so you can regenerate it on its own.
  10. Copy a panel's prompt — use the 📋 Copy Prompt chip on any panel to copy that panel's exact full prompt (style keywords, characters, modifiers, location, and action) to your clipboard — great for testing or tweaking a prompt in another image tool. If a panel has no content, the chip shows ⚠ No Content instead. (This reflects any 📝 Prompt override you've set.)
  11. View / override a panel's prompt — the 📝 Prompt chip on any panel opens an inline editor showing that panel's exact prompt, positive and negative, including the preset style keywords. You can view it or edit it right there: once you modify it, the ⚡ GENERATE / 🔄 Generate buttons for that panel use your edited text instead of the interface-built prompt. The editor text does not feed back into the panel's character/location/action fields. If you then change the panel's characters, location, or action — or the global keywords, presets, or NSFW flag — the editor resets to the values drawn from those presets and the interface, discarding your override. (The override survives page reloads until such an interface change.)
  12. Reproduce a page — set a Seed in 📄 File (each page has its own); leave it blank for random results. When a seed is set, Panel N uses seed + N, so the whole page regenerates identically. The seed is saved across reloads along with your panel details. For full control, every panel has its own Seed box in its header: an empty box shows the value it will use in grey (the page seed + panel number − 1, or "random"). Type a number to override the page seed for that panel only; clear it to fall back. When a panel has no seed at all, the first time it generates it picks one and fills it into the box, so re-generating that panel gives you the same image again until you change it. A panel with several images gives each image its own seed (the panel's seed, then +1, +2 …) — tick 🎲 Same seed for every image at the foot of a panel's ⚙ Panel menu to render every image of that panel with the panel's seed instead.
  13. Back up your project — give it a name in 📄 File → Project (it shows at the top of the page and becomes the default filename). 📄 File → Project → Backup Project saves everything (project name, page setup, keywords, NSFW flag, all pages' panel details, saved characters/locations, layout) as a .json file. 💾 Save… never asks: it silently overwrites the file you chose with Save as… (remembered even after a reload), or downloads to the default name if you haven't chosen one yet; 💾 Save as… always asks for a path and filename and confirms before overwriting an existing file. Where the browser supports it you can choose any folder on your device; otherwise the file is simply downloaded. ⬆ Import Project restores a saved file later — even on another device: a .json restores the settings, and a project .zip restores the settings and repopulates every generated panel image (all pages) back into the page. Importing replaces the current project entirely (including image protection), so if you have a project in progress it asks first whether to save it: Save backs the current project up and then imports, Continue imports without saving, Cancel aborts. All menu settings also survive page refreshes automatically. Every panel also has an ⬇ Export chip — it downloads the same single JSON file containing all panels' settings, so exporting from any panel backs up the whole project. To back up your generated images too, use 📄 File → Export Project (.zip): it bundles the settings JSON plus every generated panel image (all pages) into one .zip. Images only live in the page until you reload, so export them before then.
  14. View modes — ▦ Storyboard (top of the page) temporarily hides the whole UI and shows every panel's representative image as a comic-page grid — panels with no image yet get a placeholder. The 🔍 Focus chip on a panel opens single-panel view: the full page is hidden and just that panel fills the screen, so you can edit it without scrolling. Navigate with the ◀ Prev / Next ▶ buttons, the panel dropdown, the panel list on the left (landscape only), or the ↑/↓ arrow keys; Esc or ← Back to page returns you. Both views reflect the current number of panels and their titles.
  15. NSFW — leave unchecked to force SFW output; check it (in 🎨 Edit) to let the model follow your prompts without filters.

Tip: generated images live only in this page until you reload — if you want to keep one, screenshot it.
