## Original request (verbatim)

> The screens around the hooks. Adding has to work on a phone (upload) and on a desktop; viewing has to stay out of the way until wanted; the JSON editor cannot hold binary, so it needs its own rule; and deleting an object has to say what happens to its images.

## Clarification questions & answers

### 2a. How does an image get onto an object? (Pick any.)

- **Answer:** Upload from this device (recommended); Snapshot one of this project's own generated panel images (recommended)

### 2b. Where do you see an object's reference images?

- **Answer:** Thumbnails on the Library row, tap to view full-size (recommended — out of the way until wanted)

### 2c. The JSON editor cannot hold binary image data. What does it show for refs?

- **Answer:** Locked — shown as metadata (count and sizes), never editable as text (recommended)

### 2d. You delete a library object that holds reference images. What happens to the images?

- **Answer:** They go with it, under the existing delete confirm (recommended)
